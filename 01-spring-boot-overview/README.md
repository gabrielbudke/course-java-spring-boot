<h2 align="center">
  Overview
</h2>

O foco é estabelecer as bases para o desenvolvimento de uma aplicação utilizando Spring Boot e Hibernate. 

Nesse módulo é discutido sobre os "starters" do Spring Boot, que são coleções de dependências Maven pré-configuradas que facilitam a configuração do ambiente de desenvolvimento para diferentes tipos de aplicativos Spring.

Também é estudado sobre os diferentes módulos adicionais do Spring que podem ser utilizados conforme necessário, como Spring Cloud, Spring Data, Spring Security, entre outros.
